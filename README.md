# Week 3 - React + Tailwind (PLP)

This repository contains a ready-to-submit React + Tailwind app for the Week 3 PLP assignment. It includes:

- Vite + React setup
- Tailwind configuration with dark mode
- Reusable components: Button, Card, Navbar, Footer
- Task Manager (add, toggle, delete, filter) using a custom useLocalStorage hook
- API integration with JSONPlaceholder (pagination, search, loading & error states)

## Setup
1. Ensure Node.js v18+ is installed
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`

## Build & Deploy
- Build: `npm run build`
- Deploy to Vercel/Netlify/GitHub Pages. Add the deployed URL to this README.

## Submission
Follow your GitHub Classroom assignment instructions. Commit all files and push to your repo.
